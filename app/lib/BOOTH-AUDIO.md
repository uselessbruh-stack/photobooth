# Booth audio

Sound is opt-in and synthesized locally using Web Audio; there are no audio downloads or microphone requests. All enabled buttons receive a tap sound. Menus open with a rising sound; choosing an item plays a confirmation; keyboard navigation ticks; text input uses a quiet pencil-like tick. Entry, countdown, shutter, developing, printing, completion and download use distinct cues. Muting sets the shared master gain to zero immediately, including already scheduled printer sounds.

Dropdowns reuse a keyboard-accessible listbox for print formats and frame themes. Panel artwork uses fixed corner slices, with content inset inside the drawn screws. Add new theme options to the papers catalog; they automatically appear in the scrollable menu.
