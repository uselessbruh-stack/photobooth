# Coral heart scatter

Warm blush paper with small filled coral hearts scattered around the square windows. Eight digital layouts, each with and without note space. Every photo opening stays square and transparent. Complete decorations can cross a window edge without changing the photo cutouts.

Reusable transparent PNG stamps are saved in motifs/. The pencil design uses graphite marks and one loose pencil outline around its middle photo. No note text is baked into frames.

Regenerate both themes with node --experimental-strip-types scripts/generate-coral-frame-themes.mjs.
