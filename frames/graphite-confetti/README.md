# Graphite confetti

A warm cream frame with small coral, gold, and lilac confetti. Eight digital layouts, each with and without note space. Every photo opening stays square and transparent.

Reusable transparent confetti PNG stamps are saved in motifs/. Marks use varied positions, sizes, and angles near the photo-window edges, with spacing checks to prevent overlap. They do not alter the transparent photo cutouts. No hearts or note text are baked into these frames. Dimensions are listed in dimensions.json.

Regenerate with node --experimental-strip-types scripts/generate-graphite-confetti.mjs.
