# Baby pink hearts

Sixteen exact-layout PNG overlays with genuine transparent heart-shaped photo openings. Eight layouts, each with and without note space. The full heart-shaped photo windows are the only heart motifs; no tiled decorations cross or break them.

No note text is baked into frames. Keep dimensions unchanged. The contact sheet checkerboard is only a preview; individual frame cutouts contain real alpha.

Regenerate with node --experimental-strip-types scripts/generate-heart-frames.mjs.
