# Dihbooth film

A pure-black retro frame with Dihbooth printed between square photo windows. Separate transparent PNG artwork provides aligned white meter lines, the reference-style paired white bars and gold upward triangle, and an elongated upward pause mark in each divider. Meter lines stop before the transparent photo area. No sprocket holes are used; photo windows alone are transparent. Eight layouts are available, with optional note space.

Reusable artwork is in assets/. Exact photo and label coordinates are in dimensions.json. Regenerate with node --experimental-strip-types scripts/generate-dihbooth-film.mjs.
